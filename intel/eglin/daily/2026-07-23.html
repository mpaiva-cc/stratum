Five days to the mainline. Stateless transport lands; Stratum's four servers need a verdict.

Fact: the MCP mainline final specification ships on 28 July 2026 — T-5 calendar days at brief-time — and the release-candidate blog + independent read-throughs converge on the same headline set [1][2][3][4]. Stateless: the initialize handshake is gone and there is no protocol-level session id, so every request is self-contained (protocol version, client info, capabilities travel per-request), and a remote MCP server that previously needed sticky sessions and shared session state can now sit behind a plain round-robin load balancer with an Mcp-Method routable header [2][3]. Extensions elevated to first-class: MCP Apps (server-rendered UI) and Tasks (long-running work). Authorization aligns more closely with OAuth 2.0 and OpenID Connect. Formal deprecation policy lands so downstream implementers can plan against a versioned surface. Beta SDKs (Python, TypeScript, Go, C#) are published [4].
