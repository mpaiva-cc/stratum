The people-graph query playground.

Enter a query, see what the graph returns — Postman for the people graph. Start with a person: RETURN p hands back the whole record, so you can read the entire people schema — identity, role, org, compensation, and the derived signals — at a glance. Everything runs client-side over the real served fixtures; nothing is sent anywhere.

This runs a constrained Cypher subset over the valid-time projection fixtures (people, requisitions, candidates, and the real applied_for edge). Person, cohort, structure, and pipeline queries execute against real data and return real rows; RETURN p returns the full record as JSON. The identity-as-edge, bitemporal as-of, and consent-gated layers are described in WP-01 §10 and are not executed here. Supported: MATCH · WHERE · RETURN · ORDER BY · LIMIT, with count/avg/sum/min/max; labels person · requisition · candidate; edges applied_for · reports_to.
